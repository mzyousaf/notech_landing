# Nova Labs Landing Page

A single-page marketing site for **Nova Labs** — enterprise AI automation and intelligent agents.

Built with Next.js, React, TypeScript, and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

- `/` — Main landing page
- `/chat` — Assistrio iframe chat page

## Deploy on Vercel

Import the repository at [vercel.com/new](https://vercel.com/new). Next.js is auto-detected.
